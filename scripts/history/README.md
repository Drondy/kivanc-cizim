# Geçmiş Toplu Üretim Scriptleri (Arşiv)

Bu klasörde Kıvanç'ın Çizim Atölyesi kataloğu büyütülürken kullanılan önceki toplu veri ve uygulama scriptleri SVG/ses referansı olarak saklanmaktadır.

- **Yeni çizimler eklemek için** bu eski scriptleri doğrudan düzenlemek yerine kök dizindeki güncel yeniden kullanılabilir araçları kullanın:
  - [`../render_preview.py`](../render_preview.py) — Headless Chrome SVG önizleme üretici
  - [`../add_drawings_tool.py`](../add_drawings_tool.py) — Şema doğrulayıcı, `tr-TR-EmelNeural` MP3 üretici ve `drawings.js` güncelleyici
  - [`../audit_catalog.js`](../audit_catalog.js) — Tam katalog ve ses dosyası bütünlük denetleyicisi
